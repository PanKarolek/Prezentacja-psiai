Czym jest właściwość Display?

Wszystko w HTML to tak naprawdę prostokątne pudełko (tzw. Box Model). Właściwość display określa, jak to pudełko ma się zachowywać w stosunku do innych na stronie.

  • Czy ma zająć całą linijkę dla siebie?
  • Czy ma ustawić się obok innych elementów (jak tekst)?
  • Czy można mu nadać konkretną szerokość i wysokość?

Trzy najważniejsze, klasyczne wartości to: block, inline oraz inline-block.

🧱 Elementy blokowe (display: block)

Domyślne zachowanie m.in. dla <div>, <p>, <h1>.

  • Zawsze zaczynają się od nowej linii.
  • Zajmują całą dostępną szerokość (100% rodzica).
  • Możesz im zmieniać width i height.
.pudelko {
  display: block;
  width: 100%;
}

📝 Elementy liniowe (display: inline)

Domyślne zachowanie m.in. dla <span>, <a>, <strong>.

  • Układają się jeden obok drugiego (jak słowa w zdaniu).
  • Kompletnie ignorują nadane width i height!
  • Marginesy górne/dolne mogą psuć układ strony.
.slowo {
  display: inline;
  width: 500px;
}

Zwykły tekst, a w nim Element Liniowy i obok Drugi Liniowy. Układają się ładnie w tekście, ale ignorują zadaną w kodzie wysokość i szerokość!

🤝 Złoty środek (display: inline-block)

Łączy najlepsze cechy obu światów! Często używany do przycisków i menu nawigacyjnych.

  • Elementy układają się obok siebie (jak inline).
  • Ale... szanują nadane width i height (jak block)!
.karta {
  display: inline-block;
  width: 150px;
  height: 200px;
}

👻 Znikający element (display: none)

Ukrywa element na stronie tak, jakby nigdy w kodzie go nie było.

  • Zwalnia miejsce na stronie (inne elementy przesuwają się na jego pozycję).
  • Różni się od visibility: hidden, które ukrywa element, ale zostawia po nim puste, "niewidzialne" miejsce.
.ukryty {
  display: none;
}

🛠️ Czas na Was! (Zadanie)

Napiszcie kod CSS dla 3 elementów, opierając się na display:

  1. .kafelek – ułóżcie je obok siebie z własną szerokością.
  2. .przycisk – uczyńcie go dużym blokiem zajmującym nową linię.
  3. .sekret – ukryjcie go całkowicie bez śladu.

Kod HTML:

<span class="kafelek">Opcja 1</span>
<span class="kafelek">Opcja 2</span>
<a href="#" class="przycisk">Zapisz się!</a>
<p class="sekret">Tajne hasło</p>

👀 Oczekiwany efekt:

Opcja 1 Opcja 2 Zapisz się!
(Element .sekret zniknął całkowicie z układu) 
.kafelek {
  display: inline-block;
}

.przycisk {
  display: block;
}

.sekret {
  display: none;
}
