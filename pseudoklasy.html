Czym jest pseudo-klasa?

  • Definicja: Słowo kluczowe dodawane do selektora, określające jego specjalny stan.
  • Kiedy używamy? Gdy chcemy zmienić wygląd elementu w momencie interakcji (np. najechanie myszką) lub na podstawie jego miejsca w strukturze HTML.
  • Główna różnica:
    • Zwykła klasa (.przycisk) nadaje stały wygląd.
    • Pseudo-klasa (:hover) zmienia wygląd dynamicznie, tylko gdy zajdzie warunek.

Jak tego używać? (Składnia)

Do selektora zawsze dodajemy pojedynczy dwukropek ( : ), bez spacji.

selektor:pseudo-klasa { 
  właściwość: wartość; 
}

a:hover { 
  color: red; 
  text-decoration: underline;
}

🔗 Pseudo-klasy dla linków

Dzięki nim użytkownik wie, które strony już odwiedził, a w które właśnie klika.

  • :link - normalny, nieodwiedzony link.
  • :visited - link odwiedzony w przeszłości.
a:link {
  color: blue;
}
a:visited {
  color: purple;
}
a:hover {
  color: red;
}

🖱️ Interakcje (Przyciski)

  • :hover - najechanie myszką.
  • :active - moment wciśnięcia przycisku.
  • :focus - skupienie (np. nawigacja TABem).
button:hover {
  background-color: green;
}
button:active {
  transform: scale(0.9);
}
button:focus {
    border: 3px solid red;
}

📋 Pozycja w strukturze (:first-child)

Wybiera element, który jest pierwszym dzieckiem swojego rodzica.

Istnieje też :last-child dla ostatniego elementu!

li:first-child {
  font-weight: bold;
  color: white;
  background: blue;
}

Wynik działania:

  • Pierwszy element (jestem inny!)
  • Drugi element
  • Trzeci element

🔢 Magia CSS (:nth-child)

Pozwala wybrać element o konkretnym numerze lub według wzoru.

  • (3) wybierze dokładnie trzeci element.
  • (even) to elementy parzyste.
  • (odd) to elementy nieparzyste.
li:nth-child(even) {
  background-color: #d1e7dd;
}

Wynik działania:

  • Element 1
  • Element 2 (parzysty)
  • Element 3
  • Element 4 (parzysty)

📝 Formularze w CSS

Pseudo-klasy są niezastąpione przy polach tekstowych i checkboxach.

  • :checked - gdy checkbox jest zaznaczony.
  • :disabled - gdy pole jest zablokowane.
input:disabled {
  background-color: #ccc;
  cursor: not-allowed;
}

🚫 Wykluczenia (:not)

Narzędzie dla leniwych! Pozwala nadać styl wszystkim elementom, OPRÓCZ tego wskazanego w nawiasie.

li:not(.szary) {
  color: #0d6efd;
  font-weight: bold;
}

Wynik działania:

  • Zwykły element
  • Element z klasą .szary
  • Zwykły element

🛠️ Czas na Was! (Zadanie)

Napiszcie krótki kod CSS, który zrobi dwie rzeczy:

  1. Sprawi, że przycisk po najechaniu myszką zmieni tło na pomarańczowe (orange).
  2. Sprawi, że drugi element na liście będzie miał czerwony tekst (red).

HTML do zadania:

<button>Przycisk</button>
<li>Raz</li> <li>Dwa</li> <li>Trzy</li> 
button:hover {
  background-color: orange;
}

li:nth-child(2) {
  color: red;
}

💡 Podsumowanie

  • Dynamiczność: Pseudo-klasy pozwalają reagować na interakcje (np. najechanie myszką, wciśnięcie elementu) bez konieczności używania JavaScriptu.
  • Zarządzanie strukturą: Ułatwiają stylowanie elementów bazując na ich pozycji w drzewie HTML (np. wybieranie co drugiego wiersza tabeli).
  • Składnia: Zawsze stosujemy pojedynczy dwukropek przed nazwą (np. :hover, :focus).
  • Złota zasada linków (LVHA): Ustalając style dla odnośników, trzymaj się kolejności: :link, :visited, :hover, :active.
